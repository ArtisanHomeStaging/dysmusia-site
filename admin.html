GitHub connection

Create a token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Scope it to only this one repository, with Contents: Read and write permission — nothing else.

How this actually publishes: "Publish to GitHub" commits the updated content.json straight to your repo using the token above. Vercel picks up the new commit and redeploys automatically — usually live within a minute or two. "Download" is a manual backup option if you'd rather not use a token.
